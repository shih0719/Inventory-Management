# 庫存系統操作手冊

最後更新：2026-10-28。這份手冊依照目前程式碼的行為撰寫

## 開始使用

登入、選好倉庫之後，畫面上所有的庫存資料和操作都只限於這個倉庫。

1. 用管理者給你的「使用者名稱」和「密碼」登入。登入狀態維持 24 小時，之後要重新登入。
2. 在「選擇倉庫」畫面點你要操作的倉庫。看到「您沒有任何倉庫的存取權限」時，請管理者把你加入倉庫。
3. 要換倉庫，點上方列的 🏭 倉庫名稱。手機版點右上角的倉庫名稱。
4. 要換語言，點上方列的 🌐，可選繁體中文、简体中文、English、日本語。
5. 修改密碼和登出：點右上角你名字的第一個字母。
6. 要看這份手冊：點右上角你名字的第一個字母，選「📖 操作手冊」。手機版在右上角 ☰ 選單裡。

### 角色能做什麼

| 功能 | view | manager | admin |
| --- | --- | --- | --- |
| 看總覽、庫存報表、交易歷史、AP 序號品、出貨單據 | 可以 | 可以 | 可以 |
| 進貨、出貨、調整庫存、登記 AP、建立出貨單、匯入 CSV | 不行 | 可以 | 可以 |
| 產品管理、操作日誌、使用者管理、倉庫管理、備份設定 | 不行 | 不行 | 可以 |

看不到「+ 進貨」「+ 出貨」按鈕，代表你的角色是 view。需要的話請找管理者調整。

### 找產品

上方的搜尋框可以輸入 SKU、名稱或型號。掃碼槍掃條碼也會直接輸入到搜尋框。手機上登記 AP 序號時，可以用相機掃描序號。

## 倉管：進貨、出貨與調整庫存

一次有很多品項時用「批次」，只改一個產品時用「調整庫存」。每筆異動送出後就不能修改或刪除，打錯了要再建一筆反向的異動來修正。

### 有帳與無帳

每個產品的數量分成「有帳」和「無帳」兩筆，各自計算。每一項異動都要選「帳別」，預設是有帳。出貨時只會扣你選的那一筆，有帳不夠時不會自動扣無帳。

### 批次進貨／出貨

1. 點上方的「↑ + 進貨」或「↓ + 出貨」。手機版在畫面下方。
2. 選標籤：進貨可選「入庫」或「退貨」，出貨可選「出庫」或「內部領用」。
3. 掃描或搜尋產品，輸入數量，選帳別。在數量欄按 Enter 會自動跳到下一項，可以連續掃。
4. AP 序號品不填數量，改成一台一台掃序號，數量就是掃到的序號數（見下一節）。
5. 需要的話填「批次名稱」（例如「5/22 進貨」）和備註，然後按「送出批次」。

整批是全有或全無：只要有一項不對，整批都不會寫入。有問題的項目會標出紅字，改好才能送出。常見的是「庫存不足 — 現有 N」：請確認帳別沒選錯，或減少數量。

出貨標籤是「出庫」時，送出後會自動建立一張出貨單據，可以順便填客戶、案子和出貨日期。

「內部領用」用在公司內部取用：一樣會扣庫存，序號品一樣變成「已售」、一樣要填案子，但不會建立出貨單據，也不會發通知。

借出給客戶也用「出庫」，會建立出貨單據；東西還回來時，在「+ 進貨」選「退貨」標籤。

### 調整單一產品

1. 在上方搜尋框找到產品後點它，或在總覽的「低庫存」列表點任一列，會打開「調整庫存」。
2. 在「數量變化」輸入增減量：正數是進貨，負數是出貨。畫面會顯示異動後的數量。
3. 選帳別。標籤會依正負數自動設成「入庫」或「出庫」。
4. 這裡也可以改產品的「下限」（最低庫存）。按「建立異動」送出。

數量會變成負數的異動送不出去。

## 倉管：AP 序號品

AP 序號品一台一個序號，進貨和出貨都要掃序號，不能只打數量。序號品只算在「有帳」數量裡。

每個序號的狀態只有兩種：「庫存中」和「已售」。出貨會把它變成已售，用「退貨」標籤進貨才會變回庫存中。序號在整個系統裡不能重複。

### 進貨（新序號）

有兩種方式，都會增加有帳數量：

- **批次進貨**：在「+ 進貨」加入 AP 產品，然後在它下方「掃描或輸入序號後按 Enter」，一台掃一次。手機可以按「相機掃描」。
- **序號入庫**：到「管理 → AP 序號品」，選產品後按「+ 序號入庫」，序號一行一個貼上去，再按「建立序號品」。

### 出貨

1. 點「+ 出貨」，標籤選「出庫」。
2. 直接掃序號。系統會自己找到對應的產品。
3. 「案子」必填，客戶和出貨日期也建議一併填寫。沒填案子就不能送出。
4. 送出後，序號變成「已售」，並自動建立一張出貨單據。

### 退貨

客戶退回的序號品，在「+ 進貨」選「退貨」標籤再掃序號。用「入庫」標籤掃已出庫的序號，會出現「XXX 已出庫，退貨請選『退貨』標籤」。退貨後，該序號原本的案子、客戶、出貨日期會清空。

### 移倉

1. 在「AP 序號品」頁按「⇄ 移倉」。
2. 選目標倉庫，序號一行一個貼上去，按「確認」。

只有「庫存中」的序號能移倉。目標倉庫必須已經有同一個 SKU 的產品，否則會顯示「目標倉庫無此 SKU」，要先請管理者在那個倉庫建立產品。

### 數量對不上時

AP 產品顯示黃色警示，代表有帳數量和「庫存中」的序號數不一致。可以在「調整庫存」修正有帳數量，但只能往序號數的方向調。一般的進出貨仍然要掃序號。

## 業務：查庫存與出貨單據

查庫存、查序號去向、看出貨單據，所有角色都可以做。要自己出貨或修改出貨單據，帳號需要是 manager 以上。

### 查庫存

- **快速查一個產品**：在上方搜尋框輸入 SKU、名稱或型號，看「有帳」「無帳」兩個數字。
- **看全部**：點「📊 庫存報表」。
- **查某一台去了哪裡**：到「管理 → AP 序號品」點產品，序號清單會顯示每台的狀態，已售的會顯示客戶。

這些結果都只是目前選的倉庫。要查別的倉庫，請先切換倉庫。

### 出貨單據

出貨單據是自動建立的：在「+ 出貨」用「出庫」標籤送出時就會產生一張。所以客戶和案子最好在出貨當下就填。

1. 到「管理 → 出貨單據」，在出貨單清單點一張看明細。
2. 「匯出 Excel」可以下載這張出貨單，給客戶或財務用。
3. 若有異動在當初沒進入出貨單，可以用「補綁既有異動」把它加進來。
4. 「刪除出貨單」只會刪掉單據本身，庫存異動仍然保留，庫存不會回復。

AP 序號品出貨後，如果要更正客戶或案子，目前畫面上沒有修改功能，請找管理者處理。

## 主管：報表、低庫存與紀錄

「總覽」看今天的狀況，「庫存報表」看全部數字，「交易歷史」查每筆數量是怎麼變的，「操作日誌」查是誰做了什麼。

| 畫面 | 位置 | 用來做什麼 |
| --- | --- | --- |
| 總覽 | 點左上角系統名稱 | 品項總數、低庫存、今日異動、AP 在庫；低庫存清單和最近異動 |
| 庫存報表 | 上方「📊 庫存報表」 | 所有產品的有帳、無帳、最低庫存；低庫存警示；「⬇ 匯出 CSV」 |
| 交易歷史 | 上方「🕘 交易歷史」 | 每一筆進出；可依日期、方向、帳別、標籤、SKU、操作者篩選 |
| 操作日誌 | 「管理 → 操作日誌」（限 admin） | 登入、庫存異動、使用者與倉庫的建立、修改、刪除 |

### 出貨通知（LINE）

系統管理者設定好之後，每建立一張出貨單（「+ 出貨」用「出庫」標籤送出），LINE 群組會收到一則訊息，寫著出貨單號、倉庫、客戶、案子、操作者，以及每項產品出貨前後的數量。一張出貨單只發一則。進貨、調整、CSV 匯入和其他標籤的出庫都不會通知。沒收到通知時，請找系統管理者；設定方式在 `docs/operations/NOTIFICATIONS.md`。

### 低庫存

數量低於「下限」就算低庫存。下限在「調整庫存」裡設定，設成 0 就不會警示。在總覽的低庫存清單點一列，可以直接補貨。

注意：總覽只用「有帳」數量跟下限比，庫存報表用「有帳 + 無帳」來比，所以兩邊的低庫存清單可能不一樣。

### 追查數量問題

帳面和實際對不上時，先到「交易歷史」用 SKU 篩選。每筆異動都有異動前、異動後、操作者和來源（手動、批次、CSV 匯入、出貨…），點一筆可以看明細。交易歷史的篩選條件會留在網址裡，可以直接把網址傳給同事。

## 管理者：產品、CSV、使用者與備份

這一節的功能都在「管理」選單裡。CSV 匯入只需要 manager 權限，其他功能都要 admin。

### 產品管理

在「管理 → 產品管理」按「新增產品」，填 SKU、產品名稱、型號、類型和最低庫存。需要逐台追蹤的產品，要勾「序號追蹤 (AP)」。

每個倉庫的產品清單是分開的。同一個 SKU 如果兩個倉庫都有，要在兩個倉庫各建一次。AP 要移倉時也需要這樣。

### CSV 匯入與匯出

按鈕在「庫存報表」頁的上方。檔案用 Big5 編碼，Excel 直接打開不會亂碼。

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| SKU | 是 | 已存在就更新，不存在就新增 |
| Name | 是 | 產品名稱 |
| Type | 是 | `ap`（序號追蹤）或 `normal`。還有序號品的 AP 產品不能改成 `normal` |
| Model | 否 | 型號 |
| IsAccount | 否 | 有帳數量 |
| NoAccount | 否 | 無帳數量 |
| MinStock | 否 | 最低庫存，空白就保留原值 |

- 數量填的是「目標值」，不是增減量。例如現在有 10，檔案填 12，系統會建立一筆 +2 的「調整」異動。
- 一列一列匯入：有問題的列會列出錯誤，其他列照樣匯入。這和批次進出貨的「全有或全無」不同。
- AP 產品的有帳數量不能用 CSV 改，要改的那列會失敗。

### 使用者與倉庫

1. 「管理 → 倉庫管理」：新增或修改倉庫。倉庫名稱不能重複。
2. 「管理 → 使用者管理」：按「新增使用者」，填使用者名稱、密碼，選角色（view、manager、admin）和所屬倉庫。
3. 每個人都能用名稱為 default 的倉庫，其他倉庫要另外加入。

### 備份

系統每 6 小時自動備份。在「管理 → 備份設定」可以設備份保留期，並開啟「每週 Email 備份」。Email 備份要填 Gmail 信箱和 16 碼的「應用程式密碼」（不是 Gmail 登入密碼）。填好後先按「寄送測試信」確認能收到。

## 常見錯誤訊息

訊息裡的文字跟畫面上顯示的一樣，可以用關鍵字在這裡搜尋。

| 訊息 | 原因 | 怎麼處理 |
| --- | --- | --- |
| 庫存不足 — 現有 N | 出貨數量比選的帳別現有數量多 | 確認帳別（有帳／無帳），或減少數量 |
| 驗證失敗，共 N 筆錯誤，整批取消 | 批次裡有項目不對，整批都沒寫入 | 改好標紅的項目後重新送出 |
| 商品 X 庫存已變動，請重新送出 | 你填單時，別人剛好動了同一個產品 | 直接再按一次送出 |
| AP 商品請改掃描序號 | AP 產品不能只填數量出貨 | 刪掉這項，改掃序號 |
| 請掃描進貨的序號 | AP 產品進貨沒掃序號 | 在這項下方掃序號 |
| 出貨含 AP 序號時，案子為必填 | 沒填案子 | 填入案子後送出 |
| 已出庫，退貨請選「退貨」標籤 | 用「入庫」掃了已賣出的序號 | 標籤改成「退貨」 |
| 已在庫 | 這個序號已經登記過，還在庫存裡 | 確認是不是掃到別台，或重複掃 |
| 屬於其他商品 | 序號登記在另一個 SKU | 確認產品選對了沒有 |
| 此倉庫找不到序號 | 序號在其他倉庫，或還沒登記 | 確認目前選的倉庫 |
| 目標倉庫無此 SKU | 移倉的目標倉庫還沒有這個產品 | 請管理者先在目標倉庫建立同 SKU 的產品 |
| 無該倉庫的存取權限 | 帳號沒有被加入那個倉庫 | 請管理者在使用者管理加入 |
| SKU 格式無效 | SKU 只能有英文字母、數字、`-` 和 `_` | 修改 CSV 裡的 SKU |
| 缺少必要的欄位 | CSV 第一列沒有 SKU、Name、Type | 先匯出一次 CSV，照它的欄位填 |
| 無法解析 CSV 檔案 | 檔案不是 CSV，或編碼不是 Big5／UTF-8 | 在 Excel 另存成 CSV 再匯入 |
| 該商品仍有 N 筆序號紀錄 | 要關閉序號追蹤或下架的產品還有序號 | 先處理完這些序號，或請管理者協助 |
